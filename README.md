ข้อที่ 1 — แนะนำตัว
1.ประกาศตัวแปรโดยใช้  const เพราะ ค่าของตัวแปรนี้ไม่ควรถูกแก้ไข
2.ใช้ Tempplate Literal เพื่อให้โคดอ่านง่ายและจัดรูปแบบบัตรแนะนำตัวได้สวยงาม
3.${} ช่วยให้แทรกค่าตัวแปรและผลการคำนวณได้สะดวก
4.การคำนวณปีจบ (2569 + graduationYear) ทำให้บัตรแสดงปีจบอัตโนมัติ ไม่ต้องพิมพ์เลขเอง

ข้อที่ 2 — ชนิดข้อมูลและ typeof
1.ประกาศตัวแปรและตรวจชนิด โดยใช้ typeof 
2.typeof null => "object" จริง ๆ ควรจะเป็น null แต่เป็นขอ้ผิดพลาดของ js
3.การเปรียบเทียบต้องระวังเรื่องชนิดข้อมูล "===" จะตรวจทั้งค่าและชนิด
4.การแปลง string => number ด้วย Number() ทำให้สามารถนำไปคำนวณและเปรียบเทียบได้ถูกต้อง
5.การใช้ toFixed(1) เป็นกำหนด จุดทศนิยมให้มี 1 ตำแหน่ง

ข้อที่ 3 — เครื่องคิดเลขคะแนน
1.ใช้ const  เพราะค่าคะแนนไม่ควรเปลี่ยน
2.ใช้สูตร (workshopRaw / 60) * 20  เพื่อปรับคะแนน workshop ให้เป็นสัดส่วนเต็ม 20
3.ใช้ .toFixed(2)  เพื่อควบคุมการแสดงผลทศนิยมให้เป็น 2 ตำแหน่ง
4.ใช้ Template Literal  เพื่อจัดรูปแบบข้อความหลายบรรทัดและแทรกค่าตัวแปรได้ง่าย
5.ใช้การคำนวณ 80 - totalScore  เพื่อบอกว่าขาดอีกกี่คะแนนถึงเป้าหมาย

ข้อที่ 4 — ตัดเกรดจากคะแนน
1.สร้าง function ตัดเกรด 
2.ตรวจสอบข้อมูลนำเข้าก่อน (score < 0 หรือ score > 100) 
ถ้าไม่อยู่ในช่วง 0–100 จะคืนข้อความเตือน "คะแนนต้องอยู่ที่ 0 - 100"
ใช้ || (OR) เพื่อรวมเงื่อนไขผิดพลาดทั้งสองกรณี
จากนั้นใช้ if / else if ไล่ตรวจช่วงคะแนนตามลำดับจากมากไปน้อย
ถ้าไม่เข้าเงื่อนไขใดเลย คืนค่า "F"
3.สร้าง Array ของคะแนนทดสอบหลายกรณี ใช้ for...of เพื่อวนซ้ำแต่ละค่าใน Array
เรียกใช้ toGrade(s) แล้วแสดงผลออกมา
4.ใช้ return ในฟังก์ชัน เพื่อคืนค่าผลลัพธ์ออกมา ไม่ใช้ console.log

ข้อที่ 5 — ระบบสั่งอาหาร
1.สร้าง function ราคาตามเมนู
2.ใช้ switch เพื่อเลือก ราคาตามชื่อเมนูใช้ fall-through 
รวมหลาย case ที่ราคาเท่ากัน (50 บาท)  เพื่อลดการเขียนซ้ำ
3.default คืนค่า 0 ถ้าเมนูไม่อยู่ในรายการ
4.ใช้เป็น return เพราะ จะไม่ไม่ต้อง break หลายครั้ง
5.สร้าง Array ของออร์เดอร์ แต่ละรายการมี menu, size, qtyใช้ for...of 
วนซ้ำแต่ละออร์เดอร์คำนวณราคาต่อรายการ
6.ใช้ total += itemTotal  รวมราคาทั้งบิล
7.ใช้ Template Literal (${...}) แสดงผลข้อความพร้อมค่าตัวแปรได้สะดวก
